# Simplelink LPF2

This folder contains the low-level support required from the
Simplelink LPF2 SDK.

### Version

The current version of simplelink_lpf2 is based on
[Simplelink LPF2 8.33.00.16](https://github.com/TexasInstruments/simplelink-lowpower-f2-sdk).

## Contents

The folder-structure herein reflects the folder-structure in the
Simplelink SDK. All files required to support Zephyr have been copied
manually from the Simplelink SDK, with the exception of DPL files under
`kernel/zephyr/dpl`, which are original and maintained in this repository.

When updating to a new SDK, a comparison of the files in the 'devices'
and 'drivers' directories should be performed to pick up any new changes.

There is a simple helper script present to copy the relevant directories.

## BLE5-Stack

The TI BLE5-Stack runs as a Bluetooth LE controller for the Zephyr host on
CC13x2x7/CC26x2x7 (Zephyr driver `ti,cc13xx-cc26xx-bt-hci`).

- The prebuilt stack (`OneLib.a`) and the addresses of its BLE ROM part
  (`ble_r2.symbols`) are west blobs: `west blobs fetch hal_ti`.
- `source/ti/ble5stack` contains the stack sources built from source (ICall,
  OSAL, HCI transport layer, ROM init) as in the TI `host_test` example,
  configured as HCI controller only (`CTRL_CONFIG`, no `HOST_CONFIG`).
- `kernel/zephyr/ble` is original and maintained in this repository: the HCI
  transport glue used by the Zephyr driver, the configuration normally
  generated by SysConfig, and an OS shim for the ICall POSIX port
  (`icall_POSIX.c`).
- `ble5stack.cmake` builds all code called directly by the prebuilt stack
  with `-fshort-enums`, like the stack itself.
